## Progressive Disclosure

An agent loads what its current step needs, when the step needs it, descending only as far as the step requires:
- from [`specs/AGENTS.md`](/specs/AGENTS.md), which sends a change to the procedure that governs it,
- to that procedure's step and the reference it forks to,
- to a directory's `index.md`,
- to a file,
- and to the section a citation names.

Two ways of reading reach a file, and they stay apart. Browsing, file by file or directory by directory, goes through each directory's `index.md`, read first, and then each file it lists in order ([`specs/methodology/spec-placement/where-a-file-goes.md § Where a File Goes`](/specs/methodology/spec-placement/where-a-file-goes.md#where-a-file-goes)). A citation is read where it points, a file or a section of one however deep in a directory, with no `index.md` or `main.md` read on its way. No rule reads a `main.md` ahead of need ([`specs/methodology/spec-placement/where-a-file-goes.md § Where a File Goes`](/specs/methodology/spec-placement/where-a-file-goes.md#where-a-file-goes)). A document laid out as a folder is reached through its folder's `index.md`, its text through its `main.md`, and each of its file units through the citation naming it where it is used. So a reader, an agent or a script loads only what its work needs.

What is loaded long before it is needed sits behind everything loaded since, and competes with all of it. What is loaded at the step that needs it is at the front of the agent's attention, and carries its full weight.

Worked examples teach applying the canon's forms, as [`specs/methodology/spec-style/clear-prose.md § Clear Prose`](/specs/methodology/spec-style/clear-prose.md#clear-prose) has an example teach, and they are loaded the same way. They sit in `specs/methodology/examples/`, a tree whose path names what each example shows, as a Java package's name is its directory, so an agent that knows what it needs knows where it is. The path runs broad to narrow, a subject and then a topic within it, as `examples/construct/dag/` or `examples/time/calendar/`. The directories at one level are one kind of thing, a subject's topics the things its section of the canon defines, as the constructs and the Fact they declare are the construct subject's, each named in singular kebab-case as the canon names it ([`specs/methodology/spec-placement/where-a-file-goes.md § Where a File Goes`](/specs/methodology/spec-placement/where-a-file-goes.md#where-a-file-goes), [`specs/methodology/spec-placement/kebab-case-conversion.md § Kebab-Case Conversion`](/specs/methodology/spec-placement/kebab-case-conversion.md#kebab-case-conversion)), and one word names one concept wherever the canon writes it. An example sits under the topic it shows, whichever file states the topic's rule, and one showing two topics sits under the one it is chiefly about. The section stating a topic's rule names the topic's directory, whose `index.md` describes each example, and an agent loads an example only where its step needs one.

The glossary's terms, [`specs/methodology/glossary/glossary.md § Glossary`](/specs/methodology/glossary/glossary.md#glossary), are held in the one methodology file loaded ahead of need. An agent reads them with [`specs/AGENTS.md`](/specs/AGENTS.md) before any step, since the agent cannot know a word is one of the glossary's terms without having read them. The glossary's rules for writing an entry and for using an abbreviation are loaded as any other file is, at the step that needs them.

An agent reads what it loads from a directory in the order that the directory's `index.md` lists, a parent directory before the directories under it. That order is the one the directory's authors set ([`specs/methodology/spec-placement/where-a-file-goes.md § Where a File Goes`](/specs/methodology/spec-placement/where-a-file-goes.md#where-a-file-goes)). Progressive disclosure governs when to read, not how much. Whatever is loaded is read in full, never skimmed, and read fresh rather than recalled ([`specs/AGENTS.md § Design, Refactor, Refine § Reading Fresh`](/specs/AGENTS.md#reading-fresh)). A task whose unit is a whole directory, an audit among them, loads the whole directory.
