## Setting Up an Agent

The agent in use sets up for itself what only it can carry out, through `.ai/skills/configure-spec-of-record/`. It writes what it needs as [`specs/methodology/scope/agent-agnostic.md § Agent Agnostic`](/specs/methodology/scope/agent-agnostic.md#agent-agnostic) allows anything written for one tool.

**A review's reasoning effort.** Where an agent applies a review's level through a reviewer definition, as [`specs/methodology/design-workflow/reviews-effort.md § A Review's Effort`](/specs/methodology/design-workflow/reviews-effort.md#a-reviews-effort) has it, the agent writes one definition for each level, named `review-light`, `review-medium` and `review-high`. Each definition is set to the agent's nearest level. It gives no instructions of its own, since the brief starts a review whose task the canon holds ([`specs/methodology/design-workflow/reviews-brief.md § A Review's Brief`](/specs/methodology/design-workflow/reviews-brief.md#a-reviews-brief)), and an audit follows its own skill's instructions. The agent keeps the definitions out of version control through the checkout's own exclude file, `.git/info/exclude`, so its setup changes no committed file.
