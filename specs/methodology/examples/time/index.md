# Spec of Record: Time, Worked Examples

**Reference Key:** File

**Required:** Description

| File | Description |
|---|---|
| `calendar/` | Dates computed on the Gregorian calendar and on a calendar of business days: months added, a month's end kept, a date moved to a business day and business days counted |
| `trigger/` | Time triggers, `after` an amount, `at` an instant and `when` a condition, a condition on a clock other than the wall clock among them |
| `value-in-force/` | A value in force from a date on, read at an instant, and a period a change falls within split by the instants its reads name |
