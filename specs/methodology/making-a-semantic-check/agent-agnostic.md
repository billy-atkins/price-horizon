## Agent Agnostic

This check reads the instructions for anything that assumes one particular agent.

**The candidates, then the files in full.** Where a candidate list comes with the check, the reader takes it as a guide to each line that names a vendor, a model or a path only one tool uses. The reader then reads the files in full, as [`specs/methodology/making-a-semantic-check/main.md § Making a Semantic Check`](/specs/methodology/making-a-semantic-check/main.md#making-a-semantic-check) has a candidate list used. The reader puts the test of [`specs/methodology/scope/agent-agnostic.md § Agent Agnostic`](/specs/methodology/scope/agent-agnostic.md#agent-agnostic) to each instruction.
