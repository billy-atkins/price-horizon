## The Technical Overview Against the Code

This check reads the technical specs' `architecture.md` against the code it describes. [`specs/methodology/spec-placement/index-architecture-detail.md § What an Overview Describes`](/specs/methodology/spec-placement/index-architecture-detail.md#what-an-overview-describes) has that overview describe the code that carries out the application specs.

The reader reads what the overview says about the code with the code open, as [`specs/methodology/making-a-semantic-check/main.md § Making a Semantic Check`](/specs/methodology/making-a-semantic-check/main.md#making-a-semantic-check) has a passage read beside its source. A finding is something the overview says that the code does not bear out.
