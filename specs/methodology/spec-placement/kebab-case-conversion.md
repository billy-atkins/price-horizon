## Kebab-Case Conversion

Wherever the canon asks a name in kebab-case, the name is written by one conversion: its letters lowercased, an ampersand written as the word *and*, an apostrophe dropped, the letters `a` to `z` and the digits kept, and each run of any other characters one hyphen, none leading or trailing. So two agents converting one term write one name. A rule asking a name in kebab-case decides the name's words by its own rule, and its characters by this one.
