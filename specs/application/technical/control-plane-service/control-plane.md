## Control Plane

The control plane is a named capability, not a configuration file. It is the client-facing surface ([`specs/application/product/tenant-administration/reference-data-management.md`](/specs/application/product/tenant-administration/reference-data-management.md), [`specs/application/product/tenant-administration/business-unit-settings.md`](/specs/application/product/tenant-administration/business-unit-settings.md), [`specs/application/product/tenant-administration/data-source-connections.md`](/specs/application/product/tenant-administration/data-source-connections.md), [`specs/application/product/tenant-administration/review-queues.md`](/specs/application/product/tenant-administration/review-queues.md), [`specs/application/product/tenant-administration/audit-log-visibility.md`](/specs/application/product/tenant-administration/audit-log-visibility.md), [`specs/application/product/tenant-administration/application-log-control.md`](/specs/application/product/tenant-administration/application-log-control.md)) for managing everything in [`specs/application/technical/data-model.md § Core Data Model`](/specs/application/technical/data-model.md#core-data-model) that varies by business unit, without involving Acme AI in routine changes. It draws the same line as [`specs/application/technical/engineering-and-production-considerations.md § Engineering and Production Considerations`](/specs/application/technical/engineering-and-production-considerations.md#engineering-and-production-considerations): mechanism stays canonical, and tuning is configuration. A Decision Table over the configuration surfaces states that line ([`§ Control Plane § Configuration change path`](#configuration-change-path)).

The control plane service also serves read-only views of installation-wide values. The views [`specs/application/product/platform-and-compliance-operations/versioned-upgrades.md § Versioned Upgrades`](/specs/application/product/platform-and-compliance-operations/versioned-upgrades.md#versioned-upgrades) promises show the application version the installation is pinned to and each model's pinned version ([`specs/application/technical/engineering-and-production-considerations.md § Engineering and Production Considerations`](/specs/application/technical/engineering-and-production-considerations.md#engineering-and-production-considerations)). A Control plane admin reads them on this surface, and a Platform admin reads them through Acme AI's own tooling. The view [`specs/application/product/tenant-administration/audit-log-visibility.md § Audit Log Visibility`](/specs/application/product/tenant-administration/audit-log-visibility.md#audit-log-visibility) promises shows the audit log's retention_period currently in effect, and a Control plane admin reads it on this surface. The view [`specs/application/product/platform-and-compliance-operations/deployment-topology.md § Deployment Topology § Frontier Models`](/specs/application/product/platform-and-compliance-operations/deployment-topology.md#frontier-models) promises shows the kinds of model call the installation's configuration lets reach a frontier model provider ([`specs/application/technical/model-registry.md § Model registry`](/specs/application/technical/model-registry.md#model-registry)). A Control plane admin reads it on this surface too. Any Control plane admin claim reads the same installation-wide value, whichever business unit the claim is scoped to. No view can change what it shows. A Platform admin's read is Acme AI access through PriceHorizon's systems, recorded in the audit log like any other ([`specs/application/technical/engineering-and-production-considerations.md § Engineering and Production Considerations § Security and governance`](/specs/application/technical/engineering-and-production-considerations.md#security-and-governance)); a Control plane admin's is not.

[`specs/application/technical/architecture.md § Architecture Overview § Diagrams § Layer Composition`](/specs/application/technical/architecture.md#layer-composition) renders this.

The bounds below apply to a self-service change to the surfaces they name:

- **Reference data.** A Business Unit, Geography or Competitor entry is added, disabled and has its display label renamed at any time. Its code is changed only before ingested data first uses it, and is corrected afterward through Entity Alias. A new Geography entry specifies either its parent in the hierarchy or, for a country-level entry with no parent, its own currency, for the reason the currency field of [`specs/application/technical/data-model.md § Core Data Model § Reference and Master Data § Geography`](/specs/application/technical/data-model.md#geography) gives.
- **Materiality and dead-zone thresholds.** These thresholds are set within bounds Acme AI provides as defaults ([`specs/application/product/tenant-administration/business-unit-settings.md § Business Unit Settings`](/specs/application/product/tenant-administration/business-unit-settings.md#business-unit-settings); for the materiality thresholds, [`specs/application/technical/query-service/layered-output-synthesis.md § Open Questions [Name: Default Materiality Thresholds]`](/specs/application/technical/query-service/layered-output-synthesis.md#open-questions)).
- **The application log threshold.** The threshold is lowered toward trace ([`specs/application/technical/engineering-and-production-considerations.md § Engineering and Production Considerations § Security and governance`](/specs/application/technical/engineering-and-production-considerations.md#security-and-governance)) only temporarily. A lowered threshold expires automatically rather than persisting.

The installation-wide audit log retention_period ([`specs/application/technical/engineering-and-production-considerations.md § Engineering and Production Considerations § Security and governance`](/specs/application/technical/engineering-and-production-considerations.md#security-and-governance)) is governed and raise-only. A decrease lies outside this surface entirely, by design: the control plane service's write path rejects any submitted value lower than the setting's current value.
